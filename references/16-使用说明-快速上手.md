# 16　使用说明（快速上手）：告知端口地址 → 确认设备开启 → 改名

> 面向第一次使用本 skill 的人，适用于任何 GNS3 工程。读完这一篇即可开始，其余 01~15 按需查阅。

## 一、把 GNS3 的端口地址告诉 AI（通用方法）

GNS3 中每台启动的设备，都会在模拟器主机上开放一个 **telnet 控制台端口**。
AI 不猜测端口——需要你**告知**，或让它**扫描**。查端口有两种方法：

**方法 A：在 GNS3 界面里看**
- 在拓扑图中**选中（单击）设备**，GNS3 底部状态栏会显示该设备的 console 端口号；
- 逐台记录「设备名 → 端口号」，整理好后一次性告诉 AI。

**方法 B：让 AI 扫描（推荐，省事且不易错）**
- 直接对 AI 说：

> 帮我扫描 `<模拟器主机IP>` 的 `<端口范围>`（如 5000–5200）。

- AI 会用 `scripts/connect.py scan` 扫出开放端口，并连上识别设备类型
  （VPCS 终端 / RGOS 交换机 / RGOS 路由器），列出「端口 → 设备」对照表**请你确认**。

**告知格式**（通用模板，复制后替换尖括号内容）：

> 模拟器主机 IP 是 `<模拟器主机IP>`。端口映射：`<设备名>=<端口>`、`<设备名>=<端口>`、……（逐台列全）

> 注意：GNS3 按**设备启动顺序**动态分配端口，同一工程每次打开端口都可能不同，
> **以当次界面显示或扫描结果为准**，不要沿用上一次的旧映射。

## 二、AI 会先确认所有设备已开启（通用流程）

拿到地址后，AI **不会立刻下发配置**，而是先做开机确认：

1. **逐一探测**每个端口是否可 telnet 连上、是否有命令行回显；
2. 输出**在线清单**：✅ 在线设备 / ❌ 连不上的设备；
3. 有离线设备时，AI 会**询问你**：是没在 GNS3 里启动，还是端口给错了；
4. 全部设备在线、且端口对应关系经你确认后，才进入需求分析与配置阶段。

**你要做的**：在 GNS3 里启动所有设备（右键设备 → Start，或工具栏 Start/Resume all），
等图标全部变绿后，告诉 AI「设备都开好了，请检查」。

## 三、设备改名（通用方法）

进入配置前，AI 会**先询问你**两件事（不会擅自改）：

1. 是否按题面/实验要求给每台设备改名；
2. 是否同步把 GNS3 的 shell/终端对话框标题也改名，便于区分。

你确认后，AI 按设备类型执行。**RGOS 交换机/路由器**：

```
Switch> enable
Switch# configure terminal
Switch(config)# hostname 新名称
新名称(config)# write
```

- 提示符从 `Switch` 变成新名称即改名成功；
- `write` 保存到 startup-config，重启不丢。

**VPCS 终端**：提示符本身即名称（如 `PC1>`），默认无需改名，也不支持 `hostname`。

改名完成、经你确认后，后续所有配置与验证都按新名称引用设备。

## 三·五、观摩配置过程（可选，推荐）

开始下发配置前，AI 会**询问你**：是否打开各设备的观摩窗口。

同意后，AI 运行 `scripts/open_console.py`：自动在你的机器上查找已安装的终端工具
（Xshell / SecureCRT / PuTTY / MobaXterm / WindTerm——依次查注册表、安装目录、PATH、
**桌面便携版**），然后按端口映射批量打开每台设备的 telnet 窗口。
这样 AI 每敲一条命令，你都能在窗口里实时看到设备的回显。

- GNS3 console 支持多连接，观摩窗口和 AI 的配置通道互不影响；
- 一台工具都没装时，AI 会打印 `telnet <IP> <端口>` 清单，你可用系统自带 telnet 手动连；
- 不需要观摩就直接拒绝，不影响配置。

## 四、常见问题（快速排障）

| 症状 | 处理 |
| --- | --- |
| 端口连不上 | 该设备在 GNS3 里是否已启动（绿色）？IP 是否为模拟器主机？→ 让 AI 重新扫描核对 |
| 连上无回显 | RGOS 还在启动，等 10–30 秒；AI 会自动发回车唤醒 |
| 端口与上次不一样 | 正常现象：GNS3 按启动顺序动态分配，以当次扫描结果为准，把新映射告诉 AI |
| 改名后提示符没变 | 确认处于全局配置模式 `(config)#`，而不是接口模式 `(config-if)#` |

> 相关细节见 `01-连接与发现.md`（扫描与识别）、`03-命令规则与基本配置.md`（hostname/write）。
