# 17　GNS3 拓扑自动搭建（图片 → 拓扑 → 自动接管）

> 闭环能力：用户给一张拓扑图片 + GNS3 API 地址，AI 完成「解析图片 → 建项目 → 放节点 → 连线 → 启动 → 端口映射落盘 → telnet 接管配置」全过程，用户零操作。

## 一、凭据需求（先讲清楚）

| 通道 | 用途 | 是否需要凭据 |
| --- | --- | --- |
| **GNS3 API（HTTP）** | 建项目/节点/链路/启动、查端口 | 通常**不需要**（GNS3 VM 默认无认证；若有认证则要用户名密码） |
| **设备 telnet 端口** | 配置与验证 | 不需要（GNS3 控制台无密码） |
| **SSH** | **仅救急**：API 未开放时上去侦察/开启 | 一次性，GNS3 VM 默认 `gns3/gns3` |

> 拿到主机 IP 后 API 探测顺序：先试 `http://IP:3080/v2/version`（原生端口），不通再试 `http://IP/v2/version`（GNS3 VM 经 80 代理）；都不通才考虑 SSH 救急。

## 二、标准流程

1. **解析图片**：按 `15-拓扑截图解析.md` 把图片解析为连接表（设备-接口-对端），**列给用户确认**；
   识别不清的口逐条标注询问，禁止擅自猜。
2. **生成 topo.json**：确认后的连接表转成 `topo.json`（格式见 `scripts/topo_build.py` 头部注释）。
   设备坐标按图片相对布局给（上北下南），x 向右为正、y 向下为正。
3. **核对模板**：`python topo_build.py list-templates --api <API>`，确认图片中的设备型号
   在 GNS3 里有对应模板；缺模板停下来告知用户导入镜像。
4. **搭建**：`python topo_build.py build --api <API> --topo topo.json --start --out lab_config.json`
   - 防重名：同名项目非空直接停止，绝不覆盖现有项目；
   - 链路幂等：已存在的链路自动跳过；
   - 建后自检：逐台核对设备名与图标，不符立即报错（见"三、已知坑"）。
5. **自动接管**：`lab_config.json` 里已有「设备名 → telnet 端口」映射，无需再扫描猜端口，
   直接进阶段 0 后半段（唤醒/enable/读版本），随后询问改名（见 16 号文档）。

## 三、已知坑（实测 GNS3 2.2.52，务必遵守）

- **建节点分两类**：qemu/docker/iou 模板走全属性 `POST /projects/{pid}/nodes`（GET 模板属性、
  剔除模板级字段后作为 `properties` 传入）；builtin（vpcs/cloud/nat/ethernet_switch 等）
  同样走 `POST /nodes` 且必须带 `node_type` + `compute_id:"local"`，无 properties。
  混用会报 `node_type is required` 或 `Compute ID None doesn't exist`。
- **重名自动 +1（同项目内）**：GNS3 只保证**项目内**设备名唯一——若项目里有同名残留节点
  （常见于上一次搭建失败的残留），请求 `R2` 会被静默改成 `R3`。
  **建节点后必须核对返回 name 与期望一致**，不一致立刻停止并排查残留，禁止"将错就错"。
- **PUT 改名不可靠、PUT 图标可靠**：`PUT /nodes/{id}` 改 name 常返回 200 但不生效
  （stopped/started 均可能静默忽略）；而改 symbol 生效。**可靠的改名路径**：
  关闭项目 → 编辑服务器上项目目录里的 `<项目名>.gns3`（先备份）→ 重新打开项目。
  ⚠️ 重开后 **console 端口可能重新分配**，必须重新跑 `status` 更新端口映射。
- **symbol 不在 properties 里**：图标是节点级字段，全属性创建时必须单独在 payload 顶层
  带上 `symbol`（取自模板），否则设备图标掉成默认 `computer.svg`（路由器显示成电脑）。
  建后核对 symbol，不对就用 PUT 补上。
- **端口动态分配**：console 端口由 GNS3 启动时分配，以 `status` 动作为准，不写死。
- RGOS qemu 启动慢（30–60s 内核引导），启动指令下发后**等够时间再连**，避免误判离线。

## 四、不做的事

- 不删除、不修改、不启动/停止**任何已有项目**；只操作本次新建的项目。
- 图片识别结果未经用户确认前，不执行搭建。
