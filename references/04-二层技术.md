# 04　二层技术（VLAN / Trunk / 聚合 / MSTP / 端口安全 / BPDU）

## 4.1 VLAN 与 Trunk
```
vlan 10
 name Office
vlan 20
 name Guest
!
interface gigabitEthernet 0/2
 switchport mode trunk          ! 默认放行全部 VLAN
! 如需限制：switchport trunk allowed vlan add 10,20   （all/add/remove/except）
!
interface gigabitEthernet 0/3
 switchport mode access
 switchport access vlan 20
```
> 课件建议 Trunk 只配 `switchport mode trunk`（默认允许所有 VLAN）；
> `switchport trunk allowed vlan` 需要带 `all/add/remove/except`，漏写会丢 VLAN。

## 4.2 链路聚合（AggregatePort）
```
interface range gigabitEthernet 0/0-1
 port-group 1                   ! 把物理口加入聚合组 1
 exit
interface aggregateport 1
 switchport mode trunk
 exit
aggregateport load-balance src-dst-mac
```
- 两端都要建 `aggregateport 1`，成员口配置会被聚合口接管。
- `show aggregateport 1 summary` 看成员与状态；`show aggregatePort load-balance` 看算法。

## 4.3 MSTP 多实例（收敛与负载分担）
```
spanning-tree
spanning-tree mode mstp
spanning-tree mst configuration
 name ruijie                    ! 域名必须全网一致
 revision 1                    ! 修订号必须全网一致
 instance 1 vlan 10
 instance 2 vlan 20
 exit
spanning-tree mst 1 priority 4096   ! MST1 根（越小越优）
spanning-tree mst 2 priority 8192   ! MST2 备
```
- **`name` 和 `revision` 必须全网一致**，否则实例无法对齐。
- 双上行场景：让 S1 当 MST1(VLAN10) 根、S2 当 MST2(VLAN20) 根，实现负载分担。

## 4.4 端口安全（接入终端）
```
interface gigabitEthernet 0/2
 switchport port-security
 switchport port-security maximum 1
 switchport port-security violation shutdown
```
- `violation shutdown`：违规后端口关闭，需 `shutdown`/`no shutdown` 恢复。

## 4.5 BPDU Guard（防私接交换机）
- **只配在终端（access）接口**，不要开全局 `portfast bpduguard default`（会误伤上联 trunk）：
```
interface gigabitEthernet 0/2
 spanning-tree portfast
 spanning-tree bpduguard enable
```
- 验证：`show spanning-tree summary`、`show spanning-tree interface gigabitEthernet 0/2 detail`。
