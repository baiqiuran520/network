# 08　高级路由交换（RGSE / Expert 级别）

本文覆盖 **RGSE（Ruijie Genius Senior Expert）级别**的高级路由交换主题。
数据通信基础（VLAN / Trunk / 链路聚合 / MSTP / VRRP / OSPF / DHCP / ACL / NAT / 端口安全 / BPDU 防护）
见 `04~06` 篇，那是 RGSA（Associate）与 RGSP（Professional）级别的核心。

> 本 skill 不涉及 RCIE / WLAN / 安全产品等专项，遇到 SR、VXLAN、无线 AC/AP、防火墙等需求
> 不属于本三级别范围，请另寻对应资料。

| 技术 | 是什么 / 何时用 | 关键命令入口 |
| --- | --- | --- |
| BGP | 自治系统（AS）间路由；用路径属性控制选路 | `router bgp <as>`、`neighbor`、`network`、`show ip bgp`、`show ip bgp neighbors` |
| BGP 选路原则 | 多出口/多宿主场景控制入向/出向流量 | 权重 → Local Pref → 本地起源 → AS-PATH 长度 → Origin → MED → EBGP>IBGP → IGP 度量 → EBGP 最老 → Router-ID 最小 |
| Local Pref / MED / 团体 | 影响 IBGP/EBGP 选路的常用属性 | `bgp default local-preference`、`neighbor x.x.x.x route-map`、`route-map` 设置 `set local-preference` / `set metric` / `set community` |
| IS-IS | 运营商/大型网络内 IGP，分层（L1/L2），与 OSPF 同类 | `router isis`、`net <area>`、`is-type level-1-2`、`show isis` |
| MPLS | 标签转发，用于 VPN 骨干、流量工程 | `mpls ip`、`label-switching`、`show mpls ldp neighbor` |
| MPLS VPN | 基于 MP-BGP + 路由区分（RD/RT）的多租户 L3 VPN | `ip vrf`、`route-target`、`address-family vpnv4`、`show ip vrf` |
| 组播 | 一对多高效分发（视频/会议） | `ip multicast-routing`、`ip pim`、`ip igmp` |
| QoS | 拥塞管理/避免、流量整形、优先级标记 | `class-map`、`policy-map`、`interface ... service-policy` |
| IPv6 | 双栈/纯 IPv6 地址规划与路由 | `ipv6 address`、`ipv6 ospf`、`ipv6 nd` |
| VSU（虚拟化） | 多台盒式交换机虚拟成一台，简化管理/提升可靠性 | `vsl-port`、`switch virtual domain`、`device` |
| 路由重分布 | 把一种路由协议引入另一种（如 OSPF↔BGP） | `redistribute`、`default-metric`、`route-map` 过滤，注意防环与度量 |

**易错提醒（详见 `10-蒸馏速查-易错点.md`）**
- BGP 邻居起不来先查 TCP 179 可达 + `neighbor` 的 AS 号两端是否匹配；IBGP 需全互联或反射器。
- IS-IS 的 `net` 地址格式与区域划分最容易写错；L1 路由器默认只学区域内路由。
- MPLS VPN 的 RT 两边要能"一方 export 被另一方 import"才通。
- 重分布务必用 `route-map`/度量控制，否则容易把默认路由或环路引入。
