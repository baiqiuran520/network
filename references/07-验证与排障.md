## 7.1 验证清单（show 系列）
- 交换机通用：`show vlan`、`show interfaces status`、`show spanning-tree summary`、
  `show running-config`
- 聚合：`show aggregateport 1 summary`、`show aggregatePort load-balance`
- 可靠性：`show vrrp brief`
- 路由：`show ip ospf neighbor`、`show ip route`、`show ip interface brief`
- 服务：`show ip dhcp pool`、`show ip dhcp binding`、`show ip nat translations`
- 安全：`show access-lists`、`show port-security`
- 终端（VPCS）：`show ip`、`show arp`，以及 `ping` / `trace`

## 7.2 终端连通性验证（VPCS）
```
PC1> show ip                 ! 确认拿到地址/网关/DNS
PC1> ping <网关地址>          ! 通网关
PC1> ping <公网地址>          ! 通公网（验证 NAT + 默认路由）
PC1> trace <公网地址>         ! 看路径是否走预期（如经聚合链路/边界）
```
- VPCS 的 DHCP 握手较慢，**ping 前等几秒**再测，避免误判。
- `trace` 用于验证转发路径是否符合题面（如“走 A—B 聚合链路、不绕边界路由器”）。

## 7.3 分层排障表
| 层 | 看什么 | 常见症状 / 处理 |
| --- | --- | --- |
| 物理 | `show interfaces status` | 端口 down → `no shutdown`、查连线/速率 |
| 二层 | `show vlan` / `show spanning-tree` | VLAN 没创建/没放通；根桥错；端口被 BPDU Guard 关 |
| 三层 | `show ip interface brief` / `show ip route` | SVI 没地址；OSPF 没邻居（area/network 漏配）→ 查 `show ip ospf neighbor` |
| 路由 | `show ip ospf neighbor` | 状态非 Full → 掩码/area 不一致、链路不通 |
| 服务 | `show ip dhcp binding` | 拿不到地址 → 中继/排除范围/服务器地址错 |
| NAT | `show ip nat translations` | 上不了公网 → inside/outside 方向、池、回程路由 |
| 策略 | `show access-lists` | 隔离不生效/误伤 → 方向(in/out)、标准vs扩展、序列号 |

## 7.4 收敛等待（避免“假故障”）
OSPF / VRRP / MSTP 刚配完有几秒收敛期，**等待后再验证**，不要刚配完不通就判定失败。
若长时间不通，再按上表分层定位。

## 7.5 排障心法
1. 先看 show 状态，再比对阶段 2 的规划表。
2. 一次只改一个变量，改完立即验证，便于定位。
3. 拿不准的命令先 `?`；报错 `^` 按截断规则精简后重发。
4. 大动作前 `show running-config` 备份；必要时用 `no` 回退单条配置。
