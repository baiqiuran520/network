# 05　三层与路由（SVI / VRRP / OSPF / Router-ID）

## 5.1 SVI（交换机虚拟接口 = 网关）
```
interface vlan 10
 ip address x.x.x.x 255.255.255.0   ! 示例占位，实际按规划填写
```
- 每个用户 VLAN 配一个 SVI 作为该网段网关；两台汇聚各配一个地址做 VRRP 备份组。
- 交换互连 / 交换与路由互连常用点对点 /30（如 VLAN 99 / VLAN 100）。

## 5.2 VRRP（网关冗余）
```
interface vlan 10
 ip address x.x.x.x 255.255.255.0   ! 真实 SVI 地址（示例占位）
 vrrp 10 ip x.x.x.x                 ! 虚拟网关 IP，必须与 SVI 同网段（常用 .254）
 vrrp 10 priority 120               ! 默认 100，越大越优先成为 Master
! vrrp 10 preempt                   ! 锐捷默认开启抢占
```
- 双汇聚：A 在 VLAN10 优先级高（Master），B 在 VLAN20 优先级高，互为备份。
- 验证：`show vrrp brief`。

## 5.3 OSPF（单区域 0）
```
router ospf 1
 router-id x.x.x.x                 ! 建议用 Loopback /32，稳定且易管理
 network x.x.x.x 0.0.0.0 area 0   ! 发布 Loopback
 network <网段A> <反掩码> area 0
 network <网段B> <反掩码> area 0
 exit
```
- **Router-ID**：在 Loopback0 配 /32（如 `x.x.x.x`），OSPF 用其作标识，避免接口 down 影响。
- 边界路由器向 OSPF 注入默认路由：`default-information originate`（需本机有 `ip route 0.0.0.0 0.0.0.0`）。
- 验证：`show ip ospf neighbor`（应 Full）、`show ip route`、`show ip ospf`。

## 5.4 三层互联设计
- 交换机↔交换机三层：起点对点 /30 VLAN（如 VLAN 99）跑 OSPF。
- 交换机↔路由器：起另一个 /30 VLAN（如 VLAN 100），SW 侧 SVI、R 侧物理口配同段地址。
- 这样全网路由通过 OSPF 区域 0 互通，PC 的默认网关经 VRRP 虚拟 IP 出网。
