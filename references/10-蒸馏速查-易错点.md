## 1. 命令与排错通用
- `% Invalid input detected at '^' marker`：**^ 指向出错位置**。从该处截断重发，或修正语法后再提交；不要整行反复重试。
- 进入子视图后**提示符会变化**（如 `Switch(config-if-GigabitEthernet 0/0)#`），注意当前上下文再敲命令，很多命令只在对应子视图下有效（如 `network` 必须在 `router ospf` 下）。
- 远程登录前提：设备**必须设 enable 密码**，否则无法远程配置甚至无法登录。
- 写重复性脚本命令时，务必注意「协议配置的视图关系」，复制粘贴前确认当前所处视图。

## 2. VLAN / Super-VLAN / Private-VLAN
- **SVI 激活条件**：该 VLAN 必须有一个物理端口处于 up 状态。
- **Super-VLAN（主 VLAN）**：可建 SVI，但**不能包含物理成员口**；vlan1 不能做 super-vlan；不能嵌套、不能作为别的 super-vlan 的子 vlan。
- **Sub-VLAN（子 VLAN）**：**不能建 SVI**，只能含物理成员口；同一子 VLAN 不能属于不同 super-vlan；删除前先去掉子 vlan 身份。
- **Private-VLAN**：隔离 vlan 内部不能互访、也不能跨团体；团体 vlan 同团体可通；都只能找主 vlan 通信。

## 3. STP / MSTP
- 根桥上所有端口都是指定端口；**每条链路必须有一个指定端口**。
- 生成树收敛约需 **30s**，用户才能上网——配置后先等收敛再验证，避免「刚配完不通」的假故障。
- 防止根桥往下跑（保重要链路）：调整优先级，把根桥固定在上层。

## 4. OSPF
- **area 0 必须存在且为骨干**；所有非骨干必须直连 area 0；不能分割出多个 area 0。
- `network` 宣告：**掩码必须与路由表中一致**；只有本设备接口地址匹配才宣告；只能逐条宣告。
- **特殊区域（stub / totally-stub / NSSA 等）不能重分布**（拒绝 5 类 LSA）；**完全末节 / 完全 NSSA 不能配置虚链路**；虚链路也不能建在特殊区域上。
- `default-information originate`：**设备本身必须已有默认路由**才会下发。
- 邻居能否建立看 hello/dead 时间；能否传路由看双方是否都需要 DR/BDR。
- 常见邻居失败：`%OSPF-4-ERRRCV: mismatch area ID`（area-id 不一致）、地址配错、认证不一致。

## 5. ACL
- 书写顺序：**先写小范围，再写大范围**（匹配自上而下）。
- 标准 ACL 仅按源地址过滤，无法精细控制目的；需要按目的/端口控制请用扩展 ACL。

## 6. DHCP / 中继
- 使用 DHCP 中继（`ip helper-address`）时，**必须开启 `service dhcp`**。
- 中继的作用：告诉网关谁是服务器，**需保证网关地址与服务器之间三层可达**。
- 端口安全 IP 绑定：`switchport port-security binding <ip>`（mac 无要求，ip 必须指定）；结合 dhcp snooping 绑表可禁止手工改地址。

## 7. NAT / NAPT
- 经过 NAT 后**源地址一定会改变**——会影响依赖源 IP 做身份认证的 IPSec 等场景。
- 静态一对一映射：关系固定，即便用户不用该公网地址也无法释放给别人，**浪费地址**。
- 静态路由绑定 track 时，**需同时给出出接口和下一跳**。

## 8. BGP
- EBGP 防环：AS-path 中若出现自己的 AS 号就丢弃该路由。
- **RR（路由反射器）**：至少一方为客户端才能反射；两个非客户端之间不传递路由。
- **联盟**：成员必须全互联建立邻居。
- 邻居建立失败常见原因：对端地址配错、AS 号配错、邻居地址配错。
- EBGP **可用 loopback 建邻居**（需额外配置）；network 宣告掩码必须与路由表一致、逐条宣告。

## 9. IS-IS
- level-1 不能直接和 level-2 建立邻居，必须借助 level-1-2。
- 一个设备最多 3 个 net 地址，area-id 可以不同，但 **system-id 必须一致**。

## 10. 重分布 / 路由
- OSPF 重分布其他协议（如 rip）结尾**必须加 `subnets`**。
- **默认路由不能被重分布**；完全末节/完全 NSSA 拒绝 5 类 LSA，故不能重分布。
- 通信成立前提：沿途设备**去和回的路由都必须存在**，缺一边即丢包。

## 11. 组播 / VPN / VSU 速记
- 组播 RPF：去往组播源路由开销竞选 iif，竞选失败则剪枝。
- IPSec：非对称加密，**一把钥匙加密必须用另一把解密**；私钥自留、公钥公开。
- VSU：分裂合并时选举失败方短暂异常；**switch id 不能相同**；**抢占时延只在主设备配置**。

## 12. IPv6
- 无状态自动配置：上游下发前缀**必须是 /64** 才能结合 EUI-64 自动生成地址。
- 链路本地地址仅用于单条链路（类似 IPv4 169 段），只在广播域内通信。
