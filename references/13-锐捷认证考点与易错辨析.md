## RGSA（Associate，基础）
**网络基础**
- 考点：子网掩码只能是全 0/全 1，不能 0 和 1 在同一段交叉；MAC 48 位全球唯一。
- 易错：转发途中 **sip/dip 不变，smac/dmac 随设备变化**；三层靠 **TTL** 防环路。
- 验证：`show interface`、`show arp`、`show ip route`。

**二层与 STP**
- 考点：一个端口可对应多个 MAC；**一个 MAC 不能对应多个端口（会环路）**。
- 易错：根桥上所有端口都是指定端口；**每条链路必须有一个指定端口**；STP 收敛需约 30s 用户才能上网；TCN-BPDU 用于清除错误 MAC。
- 验证：`show spanning-tree`、`show mac-address-table`。

**VLAN 与 DHCP**
- 考点：SVI 激活需该 VLAN 有物理口 up；DHCP 中继前需 `service dhcp`，中继告诉网关谁是服务器，需保证网关与服务器可达。
- 易错：禁止手工配置地址（IPSG，依据 `show ip dhcp snooping binding` 表放行）；中继的作用对象是网关不是终端。
- 验证：`show vlan`、`show ip dhcp snooping binding`、`show ip helper-address`。

**OSPF 基础**
- 考点：**area 0 必须存在且是骨干**；非骨干区域必须与骨干相连；`network` 宣告的接口 IP 必须匹配。
- 易错：邻居建立失败先看能否收到 hello（地址错/区域 ID 不一致会报 `OSPF-4-ERRRCV mismatch area ID`）。
- 验证：`show ip ospf neighbor`、`show ip ospf interface`。

**排错通用**
- `% Invalid input detected at '^' marker`：**^ 指向出错位置**，从该处截断重发（见 `03`）。
- 无 enable 密码则无法远程配置甚至无法登录。
- 复制粘贴命令前确认当前视图（如 `network` 必须在 `router ospf` 下）。

## RGSP（Professional，中级）
**Super-VLAN / Sub-VLAN**
- 考点：主 VLAN（super）可建 SVI 但**不能含物理成员口**，是子 VLAN 的网关；子 VLAN（sub）**不能建 SVI**，只能含物理口。
- 易错：vlan1 **不能做 super-vlan**；super-vlan 间不能嵌套；同一子 VLAN 不能属于不同 super-vlan；删子 VLAN 前先去掉其子身份；vlan1 不能当 super。
- 验证：`show supervlan`、`show vlan`。

**Private-VLAN（团体/隔离）**
- 易错：**隔离 VLAN 内部不能互访、也不能和团体通信**，只能找主 VLAN；**团体 VLAN 内可通信、跨团体不能**。
- 验证：`show vlan private-vlan`。

**MSTP 与 OSPF 高级**
- 考点：一条链路上 **area-id 必须一致**；不同网络类型能否建邻居看 hello/dead 时间。
- 特殊区域：末节(4/5 拒)、完全末节(3/4/5 拒)、次末节(NSSA)、完全次末节——均**拒绝对应 LSA** 且**不能重分布**（拒绝 5 类）；**完全末节/完全次末节不能配虚链路**；认证必须一致；**area 0 不能配特殊区域**；`default-information originate` 需本机已有默认路由。
- 验证：`show ip ospf`、`show ip ospf border-routers`。

**重分布**
- 易错：可重分布直连/静态，**不能重分布默认路由**；OSPF 重分布结尾**必须加 `subnets`**；不能把 OSPF 重分布进直连/静态。
- 验证：`show ip route`。

**BGP 基础**
- 考点：EBGP 防环靠 **AS-path**（出现自己 AS 则丢弃）；邻居失败常见原因：地址错、AS 号错、邻居地址错。
- 易错：BGP 联盟内部必须全互联；`network` 掩码必须与路由表一致，且路由表中存在才宣告。
- 验证：`show bgp summary`、`show bgp neighbors`。

**DHCP 安全 / 端口安全 / Track**
- 易错：用户只能经公司 DHCP 获取且禁止手工改地址（IPSG + 端口安全）；发现私接设备 shutdown 端口 300s 后自动恢复。
- 静态路由绑定 track 时**需同时写出接口和下一跳**；NQA `rns` 检测失败/成功用 `delay up/down` 控制 track 翻转。
- 验证：`show port-security`、`show track`、`show ip route track-table`。

**VSU（设备虚拟化）**
- 易错：`switch id` 不能相同；分裂合并时选举失败方短暂恢复；抢占时延只在主设备配置。
- 验证：`show vsu`、`show switch`。

## RGSE（Expert，高级）
**BGP 高级**
- 考点：路由反射器（RR）**必须有一方是客户端**才能反射；RR 两边都是非客户端时不传递；联盟内部 AS_CONFED_SET 与 AS-SET 无异。
- 易错：vpnv4 邻居传递给下一个 vpnv4 邻居；EBGP 可用 loopback 建邻居（需改更新源/TTL）；公认必遵属性所有人都认识且必须传递。
- 验证：`show bgp vpnv4 all summary`、`show bgp neighbors`。

**IS-IS**
- 易错：**level-1 不能直接和 level-2 建立邻居，必须借助 level-1-2**；一个设备最多 3 个 net 地址，area-id 可不同但 **system-id 必须一致**；邻居起不来先查 level 配置。
- 验证：`show isis neighbors`、`show isis database`。

**MPLS / MPLS VPN**
- 易错：标签模式——保守模式只留最优、次优丢弃；**RR 和 P 之间不需要 MPLS**，BGP 下一跳改变经对方 RR 传递但对方 RR 无 MPLS；SR 用源路由、多层标签只标识关键节点。
- 验证：`show mpls ldp neighbor`、`show mpls forwarding-table`。

**组播**
- 易错：RPF 失败需剪枝；从两接口收相同组播流量时竞选 iif（看去往服务器路由开销），失败方剪枝；断言失败发剪枝；DM 模式强推、不需要才退。
- 验证：`show ip mroute`、`show ip pim neighbor`。

**IPv6**
- 易错：**无状态自动配置上游前缀必须是 64 位**才能结合 EUI-64 生成；链路本地地址仅链路内通信（类似 IPv4 169）；ospfv3 与 v2 区别在 LSA 封装与地址族。
- 验证：`show ipv6 interface`、`show ipv6 ospf neighbor`。

**重分布细节**
- 易错：`redistribute isis 1 level-2 into level-1` **必须加进程号**；跨 ISIS 级别重分布注意 level 方向。

**IPsec / VPN 与 NAT**
- 易错：经过 NAT 后**源地址必变**，影响 IPsec 身份 IP；**DPD 不能用手工 SA**（无生命周期，切换差）；非对称加密公钥加密须私钥解密；IPSec 与 NAT 共存需注意；VPN 场景：站点到站用 IPSec/GRE/L2TP，移动客户端用 SSL/L2TP。
- 验证：`show crypto ipsec sa`、`show ip nat translations`。

**QoS**
- 易错：按优先级提供差异化服务；**核心层高速转发不要加控制类配置**。
- 验证：`show policy-map interface`。
