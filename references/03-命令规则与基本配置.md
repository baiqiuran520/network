# 03　命令规则与基本配置

## 3.1 配置上下文（非常重要）
```
用户模式   Switch>          （只能看）
  enable
特权模式   Switch#          （show / write / 大部分查看）
  configure terminal
全局模式   Switch(config)#
  interface gigabitEthernet 0/1
接口模式   Switch(config-if)#
```
- **VPCS 没有 configure terminal**：直接在 `PC1>` 下敲命令（`ip dhcp` / `show ip`）。
- 子命令缩进 = 属于上一级上下文。例如在 `interface vlan 10` 内写 `vrrp 10 priority 120`。
- 退出用 `exit`，回到特权用 `end`。

## 3.2 `no` 命令与 `^` 截断规则（重点）
- 删除配置：`no <原命令>`。例：`no ip address`、`no vlan 20`、`no access-list 1`、
  `no ip access-list standard 1`（整条删更稳）。
- 设备回显里的 `^` 表示**命令行在 `^` 处被截断/报错**。上一条长命令因 `^` 失败时，
  **只需从 `^` 之前截断重发**，不必整行重试：
  ```
  no  123  123  123  123  123  123
        ^
  ```
  执行 `no 123 123 123` 即可删除上一条；后面的 `123 123 123` 是多余导致 `^`。
- `Ambiguous command`（歧义）通常是因为缩写不唯一，补全到唯一再回车。

## 3.3 拿不准用 `?` 补全
- 任意上下文敲 `?` 看可用关键字；`命令 ?` 看该命令的参数。
- 语法不确定时先 `?` 探路，再写进下发脚本，减少试错刷屏。

## 3.4 保存与备份
- 配置生效要 `write`（= `write memory`）保存到 startup-config，否则重载即丢。
- 大改前先 `show running-config` 备份（本 skill 的 `deploy.py` 每台设备下发后会自动 `write`）。

## 3.5 基本配置清单（每台设备先做）
```
enable
configure terminal
 hostname <设备名>            ! 阶段 3 确认后改
 no cwmp                     ! 关掉无关服务
 service dhcp                ! 若本设备承担 DHCP（服务器或中继）
 spanning-tree               ! 全局开启生成树
 line console 0
  logging synchronous        ! 避免回显被打断
 exit
 line vty 0 4
  logging synchronous
  login
  exit
```
随后创建所需 VLAN（`vlan 10` / `vlan 20` / `vlan 99` / `vlan 100`）。
